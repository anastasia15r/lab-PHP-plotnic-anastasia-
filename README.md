# Индивидуальная работа: Веб-приложение на Flask

##  Описание проекта
Данный проект представляет собой веб-приложение для управления заметками. Приложение поддерживает регистрацию пользователей, создание публичных и приватных записей, а также полноценную панель администратора для управления контентом.

##  Инструкция по запуску
1. **Установка зависимостей:**
   ```bash
   pip install flask flask-sqlalchemy
   ```
2. **Запуск приложения:**
   ```bash
   python app.py
   ```
3. **Доступ:**
   - Откройте браузер по адресу: `http://127.0.0.1:5000`
   - Логин администратора по умолчанию: `admin`
   - Пароль администратора по умолчанию: `admin123`

##  Функциональные возможности
- **Аутентификация:** Безопасная регистрация и вход с использованием хеширования паролей (PBKDF2).
- **Общедоступный компонент:** Главная страница с динамическим выводом публичных заметок.
- **Форма создания ресурса:** Включает 5 типов полей: заголовок (текст), текст заметки (textarea), категория (выпадающий список), приоритет (radio-buttons), статус (checkbox).
- **Поиск:** Поиск по заголовкам публичных записей.
- **Админ-панель:** Удаление любых заметок, удаление пользователей, назначение новых администраторов.

##  Сценарии взаимодействия
1. **Гость:** Заходит на сайт, видит список публичных идей, пользуется поиском.
2. **Зарегистрированный пользователь:** Создает свои заметки, управляет их приватностью в личном кабинете.
3. **Администратор:** Модерирует список всех записей и управляет правами доступа пользователей.

##  Структура базы данных
Приложение использует **SQLite**. Модель данных включает две таблицы:
- `User`: `id`, `username`, `password_hash`, `is_admin`.
- `Note`: `id`, `title`, `content`, `category`, `priority`, `is_public`, `created_at`, `user_id`.

##  Ответы на контрольные вопросы
1. **Как обеспечивается безопасность паролей?**
   Пароли хешируются с использованием соли библиотекой Werkzeug, что исключает хранение паролей в чистом виде.
2. **Как реализовано разграничение прав?**
   Используется проверка поля `is_admin` в сессии пользователя перед доступом к маршруту `/admin`.
3. **Какая архитектура используется?**
   Приложение построено на модульной архитектуре Flask с разделением на Модели (SQLAlchemy), Представления (шаблоны Jinja2) и Контроллеры (функции в app.py).
